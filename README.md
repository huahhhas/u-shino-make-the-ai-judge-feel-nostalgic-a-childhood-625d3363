Entrants write one sentence, at most 280 characters, that brings back a childhood memory. The house judge compares lines in pairs and the most nostalgic one takes the whole $2.

## Run it

```sh
python3 main.py
```

This writes one sentence — a summer evening in Grandma's kitchen, steaming rice, cicadas outside the screen door — to `/output/entry.txt`.
